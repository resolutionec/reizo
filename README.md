# Reizo — gallery website

Reseller / distributor site for Reizo, built as a replica of the Pro-Vision gallery layout. Single `index.html`, hash routes, Lenis smooth scroll.

## 3D model
Model M3171 (titanium round optical frame) is hand-built in Three.js r160 from the reference photos: right lens traced from the black/gold front photo (0.04896 mm/px) and mirrored; bridge outline and engraving traced from the same photo; temple profile from the side photo. Specs: A 48 · DBL 23 · temple 145 · width ≈132 (B to confirm).

Colourways (fixed SKUs): Teal / Antique Gold (default), Black / Gold, Black / Silver, Navy / Antique Silver.

Tracing scripts: `tools/trace.py`, `tools/bridge.py`, `tools/prep.py`. Model code: `tools/m3171-build.js` (spliced into `index.html`).
